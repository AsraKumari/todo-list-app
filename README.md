# Todo List App

A simple **Todo List App** built with **HTML**, **CSS**, and **JavaScript**. This app allows you to manage your tasks, with features like adding, deleting, and completing tasks. It also includes a **theme toggle** to switch between **light** and **dark modes**.

## 🚀 Live Demo

Check out the live version of the app here: [Todo List App](https://asrakumari.github.io/todp-list-app/)

## 💡 Features

- **Add Tasks**: Add new tasks to your list.
- **Delete Tasks**: Easily remove tasks.
- **Task Completion**: Mark tasks as completed.
- **Undo Delete**: Restore a task after deletion with a simple click.
- **Light/Dark Mode**: Switch between light and dark modes.
- **Responsive**: The app works well on both desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML**: Markup of the app.
- **CSS**: Styling and layout, including Glassmorphism.
- **JavaScript**: Functionality for adding, completing, and deleting tasks.
